# seekprice

对比报价单与合同文件（WORD/PDF），检查关键金额字段是否一致。

## 程序开发手册

### 1. 项目目标
- 分别上传 **报价单** 与 **合同文件**。
- 两类文件均支持：`WORD`（.doc/.docx）与 `PDF`（.pdf）。
- 以合同文件为基准，比对报价单中以下字段是否一致：
  - 数量
  - 金额（不含税）
  - 税率
  - 税额
  - 金额（含税）
- 若存在不一致，页面需展示：
  - 不一致信息的所有位置
  - 每处不一致的具体内容（合同值 vs 报价单值）
  - 可复制结果的功能（用于粘贴到外部系统）

### 2. 功能流程
1. 用户上传合同文件。
2. 用户上传报价单文件。
3. 系统识别文件类型（WORD/PDF）并提取文本与结构化字段。
4. 以合同文件数据为基准，逐项对比报价单对应字段。
5. 页面输出比对结果：
   - 一致：显示通过状态
   - 不一致：显示“位置 + 内容差异”，并提供“一键复制”

### 3. 核心模块建议
- **上传模块**：处理双文件上传、格式校验、大小限制。
- **解析模块**：统一将 WORD/PDF 转换为可比对的数据结构。
- **字段映射模块**：将文档中的“数量、未税金额、税率、税额、含税金额”标准化。
- **比对模块**：按“合同 -> 报价单”方向逐项比较并输出差异明细。
- **结果展示模块**：列表展示不一致项，支持复制。

### 4. 差异结果数据结构（建议）
```json
[
  {
    "position": "第2页-第3行-税额",
    "field": "税额",
    "contractValue": "1300.00",
    "quoteValue": "1200.00"
  }
]
```

### 5. 页面交互要求
- 上传区分为两个独立输入：`合同文件`、`报价单文件`。
- 比对完成后展示“总差异数”与“差异明细列表”。
- 提供“复制全部差异”按钮，复制内容包含位置与差异值。

### 6. Docker 部署要求
- 项目运行在 Docker 架构中。
- 容器服务端口固定为：`5003`。
- 启动后对外提供统一访问入口（示例）：`http://<host>:5003`。

### 7. 验收标准
- 能上传合同与报价单各 1 份（WORD/PDF 任意组合）。
- 能正确输出 5 类关键字段的对比结果。
- 不一致时，能完整展示位置与内容，并可一键复制。
